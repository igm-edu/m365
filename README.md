# m365 — Microsoft 365 Copilot 실습 프롬프트

Microsoft 365 Copilot 실무 과정 수강생이 실습 프롬프트를 바로 복사해 쓸 수 있도록 만든 정적 웹페이지입니다.
교시 구분은 교안 `[교안] Microsoft 365 Copilot 활용.pdf` 의 목차(AGENDA, p.3)를 그대로 따릅니다.

## 사용법

1. 우측 상단 **햄버거 메뉴**에서 교시와 실습 구간을 골라 이동합니다.
2. 노란 **형광펜 칸을 클릭해 직접 입력**한 뒤 **복사** 버튼을 누릅니다.
3. 하단 **이전 / 다음** 버튼(또는 키보드 ← →)으로 순서대로 진행합니다.

입력한 내용은 브라우저에 자동 저장되어 새로고침해도 남아 있습니다.
한 프롬프트 안에서 같은 항목(예: 기업명)은 한 곳만 입력하면 나머지도 함께 채워집니다.

## 내용 수정

`prompt-data.js` 의 `COURSE` 배열만 편집하면 됩니다. 빌드 과정이 없어 파일을 그대로 열어도 동작합니다.

- `period` = 교시, `sections` = 실습 구간, `prompts` = 구간별 프롬프트 카드
- `{{힌트}}` → 빈칸으로 시작 (힌트가 옅게 표시됨)
- `{{힌트|기본값}}` → 기본값이 채워진 상태로 시작 (바로 복사 가능)
- 같은 카드 안에서 힌트가 같은 빈칸은 입력값이 동기화됩니다

`index.html` 과 `prompt-data.js` 는 **반드시 같은 폴더**에 두어야 합니다.
